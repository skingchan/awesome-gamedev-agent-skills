# Seven long-term program examples

These are **reference curricula, not private transcripts, grades or completed learning records**. Each example describes a previously discussed learning direction and turns it into a reproducible AI-LTS design. Specific stage lengths and Gate tasks are *proposed defaults*, to be validated after an interactive baseline diagnosis.

| Example | Destination | Key evidence |
|---|---|---|
| [Software engineering](software-engineering.md) | Regain engineering fundamentals; design, understand and supervise AI-assisted Web/apps/tools/services | own code, architecture decisions, tests, deployed working product |
| [Mathematics](mathematics.md) | Structured math understanding and independent reasoning | fresh proof/problem solutions, derivations, transfer |
| [English](english.md) | Functional communicative proficiency across modalities | sustained comprehension and conversation, independent writing |
| [Chinese history](chinese-history.md) | Coherent chronology, causal interpretation, source criticism | timeline, primary/secondary source reasoning, essays |
| [Electronic keyboard](electronic-keyboard.md) | Go from zero to confidently playing keyboard pieces | independent note location, correct fingering/rhythm, recordings |
| [Internet demand → supply → monetization](internet-business.md) | Discover demand, acquire traffic, supply value and validate monetization | interviews, experiments, traffic, conversion and unit economics |
| [AI indie game developer](ai-indie-game-development.md) | Direct AI agents/tools to build and ship games across appropriate genres/engines | playable prototype, build/test pipeline, release readiness |

For every program start with a diagnosis; *do not* assume the plan means any learner has passed the curriculum.
